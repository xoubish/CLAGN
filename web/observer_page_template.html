About this run · the science, then the setup

Predicted S/N uses archival continuum brightness, a moonlit-sky model and seeing scaled to the target airmass; it is not broad-Hβ significance. Spectral overlays are not aperture-matched or host-subtracted. The manifold is a selection prior, not a clock.
